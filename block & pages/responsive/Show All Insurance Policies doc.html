Show All Insurance Policies API Documentation

Show All Insurance Policies APIs

 

This API service is designed to facilitate the retrieval of all Takaful policies across various non-life products.It allows users to search for policies based on the national ID of the policyholder.The API provides a RESTful interface for easy integration into various systems.API Marketplace is offering all al-Rajhi group to share their most consumed APIs in its portal to make it easy to call external entities and call each other with low-rate API call.Show All Insurance Policies From al-Rajhi takaful is publishing their three services for insurance motor rate, motor quote and motor policy in our API marketplace portal to be consumed by anyone of al-Rajhi group company.
