About Bulk Categorization

 

  • Drahim's categorization is a product provided by Drahim (an ARG subsidiary, referred to as the provider) that uses an AI engine to classify merchants and allows users to classify and modify merchant classifications.The AI engine processes bulk merchant data and compares the submitted inputs to determine whether each merchant matches its expected classification or requires updates.
  • The purpose of this project is to enable all ARG subsidiaries (referred to as consumers) to offer Drahim's bulk merchant categorization service to their customers through subsidiary digital channels.
  • The Product: Bulk Categorization is Powered by: Drahim and it's Version: Version 1.0

Description

What is the API Marketplace?
- A centralized platform that exposes APIs from ARG subsidiaries in a unified, secure, and standardized way.

What is Bulk Categorization?
- An AI-powered service that classifies a bulk list of merchants into predefined business categories. - Customers can review, confirm, and modify classifications when required.

Description

What Bulk Categorization Does:
- Automatically classifies merchants using AI.
- Allows customers to update or adjust results if needed.

How Will It Be Used (B2B)?
- Subsidiaries integrate with the API Marketplace to offer this service via digital channels. .

How It Works (Business Flow): Customer submits bulk merchant details → API Marketplace validates and routes → Categorization Service processes via AI → Results returned to the customer.

Advantages of Bulk Categorization (Business View)

- Provides accurate classification without building a new AI solution.
- Supports bulk processing to save time and effort.
- Standardized and secure access through API Marketplace.
- Faster time-to-market and centralized monitoring.

Terminologies (Business Definitions)

 

  • Bulk Categorization

    An AI-powered service that classifies multiple merchants into categories based on business type and transaction data.

  • API Marketplace

    Validates requests, applies security, and routes them to the Categorization Service.

  • Categorization

    Assigning merchants into predefined business categories (e.g., Food & Beverage, Electronics, Retail).

  • Provider (Categorization Service)

    Backend categorization engine that processes merchant lists.

  • Consumer

    Subsidiary using the service.

  • Customer

    End user interacting with the categorization service.

 

 

Key Features

 

 

  • Categorization Capabilities

    - Ability to process and classify a bulk list of merchants in a single request.
    - Automatic classification into predefined business categories using AI.
    - Support for multiple data attributes (merchant name, type, transaction history, etc.).
    - Fast response time (2–5 seconds) even for large volumes of merchants.

  • Review & Update Capabilities

    - Customers can review classification results directly through the digital channel.
    - Option to modify or update incorrect classifications before final confirmation.
    - Immediate reflection of updated classifications in the system.
    - Audit trail maintained for transparency and compliance.

  • Integration & Access

    - Standardized API exposure through the API Marketplace.
    - Secure access with OAuth 2.0 authentication and authorization.
    - Scalable to support growing transaction volumes.
    - Consistent classification logic across subsidiaries.

  • Reporting & Notifications

    - Real-time confirmation with unique reference IDs.
    - Status tracking for categorization requests (in-progress, completed, failed).
    - Exportable categorized lists for reporting and analysis.
    - Centralized notifications and logs for monitoring and audits.

 

Inputs / Outputs Samples

 

  • Inputs (Business Perspective):
    - Bulk list of merchants (customer provided)

  • Outputs (Business Perspective):
    - Categorized list of merchants (AI processed).
    - Updated classifications if modified.
