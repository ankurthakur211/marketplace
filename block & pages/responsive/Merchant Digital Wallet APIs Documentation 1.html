Merchant Digital Wallet API Documentation

Merchant Digital Wallet APIs

The API Marketplace allows users to access Neoleap's merchant digital wallet service, which helps manage merchant digital wallet requests by providing details about an employee's identity, income earned, and the time period covered by their employment.The primary objective of this project is to streamline the merchant onboarding process by determining if a merchant already exists and, if not, facilitating their registration in an efficient and secure manner.

Corporate B2B Merchant Onboarding

Endpoint: POST : /mp-merchants/v1/onboarding

This path is used to check whether merchant exists and otherwise onboard merchant.
