SPL Integration for Addresss

The API Marketplace allows users to access Neotek's SPL Integration for Address service, which helps manage SPL Integration for Retrieve national address. The primary objective of this project is to provide national address information to their customers through their respective digital channels.

Retrieve national address

Endpoint: GET : /mp-saudi-post/v1/national-address/{POINumber}

This path is used to retrieve national address for establishments by CRNumber, and for individuals by NationalID or IqamaID.

Swagger Link

Request Example

                    
  Query Params:
      "poiType":"NationalID"

  Path Variables:
      "POINumber":"1105485096"

                    
                  
                    curl --location 'https://sit.api-marketplace.alrajhibank.com.sa/apimarketplace-sit/mp-sandbox/mp-saudi-post/v1/national-address/1105485096?poiType=NationalID' \
--header 'x-request-id: 5181dce0-19dc-4f13-8e4a-038c1488f31a' \
--header 'Accept: application/json' \
--header 'Authorization: ••••••'
