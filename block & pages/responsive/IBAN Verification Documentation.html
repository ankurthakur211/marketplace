IBAN Verification API Documentation

IBAN Verification

The IBAN Verification serves as a robust tool empowering businesses and organizations to effortlessly obtain IBAN Verification Details by cross-referencing the bank account number with the Point of Identification (POI) number, typically the national ID.It streamlines and automates the validation process, ensuring that the provided bank account is not only active but also valid.

APIs

IBAN Verification

Endpoint: /mp-iban-verification/v1/verification-requests

Swagger Link

This path is used to create IBAN verification inquiry request using preferred source.
