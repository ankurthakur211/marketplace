IPS Bank Transfer API Documentation

IPS Bank Transfer

IPS Bank Transfer services provide a robust framework for secure, efficient, and cost-effective international money transfers, facilitating global commerce and financial interactions.The main goal for this project is to enable ARB to avail IPS Bank Transfer process through API Marketplace.

APIs

IPS Bank Transfer

Endpoint: /mp-accounts/v1/transfer-verification/initiate

Swagger Link

This API is used to initiate outwards transfer account verification.

Request Example

                    
Body request
{
  "Data": {
    "ClientTimestamp": "2022-02-17T18:25:43.511+03:00",
    "BeneficiaryBankId": "030",
    "BeneficiaryAddress": "Riyadh",
    "BeneficiaryIBAN": "SA2230400108071086000028",
    "RemitterIBAN": "SA4880000203608010103500",
    "BeneficiaryAccountCurrency": "SAR",
    "BeneficiaryName": "Hero",
    "BeneficiaryProxyType": "NATID",
    "BeneficiaryProxyValue": "1108613546"
  }
}                                    
                    
                  
                    
curl --location 'https://sit.api-marketplace.alrajhibank.com.sa/apimarketplace-sit/mp-sandbox/mp-accounts/v1/transfer-verification/initiate' \
