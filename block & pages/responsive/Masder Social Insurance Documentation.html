The purpose of this project is to allow ARG subsidiaries (referred as consumers) to offer the consuming Masder and SPL services service to their customers through subsidiary digital channels.

Get Person Salary Certificate

Endpoint: /mp-salary-certificate/v1/persons/{POINumber}?

Swagger Link

The API provides comprehensive personal and employment data for individuals and salary certificate of a government or non-government employee.

Request Example

                                
Path Variables:
    POINumber:1160580661 

Query Params:
    poiType:NAT
    employmentSector:Non-Gov
    birthDate:8915-78-28
    birthDateType:Hijri
    payMonth:9822-40
    payMonthType:Greg
