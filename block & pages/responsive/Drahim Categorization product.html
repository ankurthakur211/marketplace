Drahim's Categorization

 

Drahim's categorization is a product provided by Drahim that uses an AI engine to classify merchants and allows users to classify and modify the merchant's classification. The AI engine will compare the saved inputs to check whether the merchant matches the same classification or not.

About Drahim's Categorization

 

  • API Marketplace is offering all al-Rajhi group to share their most consumed APIs in its portal to make it easy to call external entities and call each other with low-rate API call.
  • Drahim's categorization is a product provided by Drahim that uses an AI engine to classify merchants and allows users to classify and modify the merchant's classification. The AI engine will compare the saved inputs to check whether the merchant matches the same classification or not.
  • The purpose of this project is to allow ARG subsidiaries to offer the Drahim's Categorization service to their customers through subsidiary digital channels.
