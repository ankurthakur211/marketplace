About Urpay Wallet Onboarding

 

  • The purpose of this project is to allow ARG subsidiaries to offer an Urpay wallet service to their customers through subsidiary digital channels.
  • The end customers of the service are any customers who can create accounts on Urpay.
  • The primary objective of this project is to enable Neoleap to avail Urpay wallet onboarding through the API Marketplace.
  • The Product: Urpay Wallet Onboarding is Powered by: Neoleap and it's Version: Version 1.0
