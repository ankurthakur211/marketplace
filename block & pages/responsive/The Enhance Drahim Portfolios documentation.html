APIs

Get Drahim Portfolios

 

Endpoint: /arb/investment-accounts

Swagger Link

This path is used to allow ARG subsidiaries to retrieve investment account (portfolio) information associated with a specific user, identified by their national ID or Iqama number.

Request Example

 

                
    Query Params:
      poiNumber=1112345543

    --header 'Accept: application/json' \
    --header 'x-request-id: 1a8a7ba1-1e51-4192-8b16-a2513488abc2' \
    --header 'Authorization: Bearer AAIgZDJiY2YwZTcyZDc5YzFkZTFkMjAyMTQxY2RlZmI1ODEfrVhpKCc3o61mtHX96LOAuw_ev7-WbJtXuARUNoBf4zcNglkVkj9xY6lVN2umwvsF8m7hrgJasEA47MXxAwiAerTNfNKeF7EZm0-KSicdGUdkvLp08ws6roFVfuvU-FgcrTQfuG7CfnFmW5dx7MzI' \
