About List Beneficiary Contracts

 

  • List Beneficiary Contracts is designed to allow ARB subsidiaries to securely retrieve a list of contracts linked to a specific beneficiary using their Beneficiary ID or CIC. The service provides OAuth2-protected access through digital channels, making it easy to view contract details in financial apps, mobile banking, or internal systems.
  • The primary objective of this project is to allow ARB entities easily access and display a beneficiary’s list of contracts in their digital platforms.
  • The Product: List Beneficiary Contracts is Powered by: ARB and it's Version: Version 1.0
