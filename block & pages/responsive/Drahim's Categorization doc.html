Drahim's Categorization APIS

The Drahim's categorization is a product provided by Drahim that uses an AI engine to classify merchants and allows users to classify and modify the merchant's classification. The AI engine will compare the saved inputs to check whether the merchant matches the same classification or not.

Categorize Merchant

Endpoint: /mp-categorization/v1/merchants/categorize

Swagger Link

It is used to utilizes the Drahim AI Engine to classify and categorize the given merchant based on the provided information.

Request Example

                    
Body Params:
{
    "Data": {
      "MerchantName": "stc pay",
      "MerchantId": "string",
      "MerchantMccCode": "string",
      "MerchantPaymentType": "string"
    }
  }

Category Vote

Endpoint: /mp-categorization/v1/merchants/category-vote

Swagger Link

It is responsible for enables the Drahim AI Engine to enhance its categorization process by incorporating user-submitted category changes for merchants. These changes are treated as votes, which the engine analyzes to improve its accuracy and provide more refined categorization results.

Request Example

                                
Body Params:
{
    "Data": {
      "MerchantId": "01J46X0AAECE5RV653B6ACJN8A",
      "UserId": "string",
      "CategoryId": "14"
    }
}
                                
                              
                                  
curl --location 'https://sit.    api-marketplace.alrajhibank.com.sa/    apimarketplace-sit/mp-sandbox/    mp-categorization/v1/merchants/    category-vote' \--header 'x-request-id:     27e3609e-c7eb-4195-8881-96308d109415' \--header 'Content-Type: application/json' \--header 'Accept: application/json' \--header 'Authorization: ••••••' \--data '{  "Data": {    "MerchantId":         "01J46X0AAECE5RV653B6ACJN8A",    "UserId": "string",    "CategoryId": "14"  }}'
