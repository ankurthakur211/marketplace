List Beneficiary Contracts API Documentation

List Beneficiary Contracts APIS

 

The primary objective of this project is to allow ARB entities easily access and display a beneficiary’s list of contracts in their digital platforms.

 

Download Postman Collection Download Sample Data

APIs

List Beneficiary Contracts

 

Endpoint: /v1/contract-beneficiary/list-beneficiary-contracts

Swagger Link

This path is used to allow ARG subsidiaries to retrieve investment account (portfolio) information associated with a specific user, identified by their national ID or Iqama number.

Request Example

 

                
Query Params:
  beneficiaryId=2196289059
  beneficiaryCIC=51
Request Body:
{
  "Data": {
    "filter": [
      {
        "Key": "CONTRACT_STATUS",
        "Value": "Pending",
        "Type": "IN"
      }
    ],
    "order": [
      {
        "Type": "ASC",
        "Attribute": "CONTRACT_ID"
      }
    ]
  }
}
                
              
                
curl --location --globoff 'https://test.api-marketplace.alrajhibank.com.sa/apimarketplace-sit/sandbox-inbound/mp-contract-beneficiary/v1/list-beneficiary-contracts?beneficiaryId=2196289059&beneficiaryCIC=51' \
--header 'accept-language: en' \
--header 'x-request-id: cd64cb43-3a27-49d7-803c-87ff2f6124b4' \
--data '{
  "Data": {

        "Type": "IN"

}'
