Consumer Digital Wallet Inquiry for Top-ups

The Consumer Digital Wallet Inquiry for Top-up API is an application that provides a streamlined and efficient process for onboarding new users onto Marketplace to be able to use all of its capabilities. The main goal for this project is to enable ARB to avail Consumer Digital Wallet Inquiry for Top-upprocess through API Marketplace.
