About Alias Inquiry

 

  • API Marketplace is offering all al-Rajhi group to share their most consumed APIs in its portal to make it easy to call external entities and call each other with low-rate API call.
  • The Alias Inquiry API is an application that provides a streamlined and efficient process for onboarding new users onto Marketplace to be able to use all of its capabilities.
  • The main goal for this project is to enable ARB to avail Alias Inquiry process through API Marketplace.
