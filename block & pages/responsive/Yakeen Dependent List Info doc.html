Yakeen Dependent List Info

Yakeen Dependent List Info

 

The Yakeen Dependent List Info displays the list of customer dependents' information by entering the user's inquiry key and the dependent's ID, showing their shared relationship and details.

APIs

List Customer Dependent Info

 

Endpoint: /mp-yakeen-customers/v1/dependent-information{DependentId}

Swagger Link

The endpoint is used to return the dependent information of the customer.

Request Example

 

                        
    Query Params:
    inquiryType:AlienDependentInfoByIqama
    inquiryKey:2200326351
    
    Path Variables:
    DependentId:2045395892
                        
                        
                        
    curl --location 'https://sit.api-marketplace.alrajhibank.com.sa/apimarketplace-sit/mp-sandbox/mp-yakeen-customers/v1/dependent-information/2045395892?inquiryType=AlienDependentInfoByIqama&inquiryKey=2200326351' \
    --header 'x-request-id: eff32975-c288-44b8-b3b4-bf08a8167649' \
    --header 'Accept: application/json' \
    --header 'Accept-Language: ar' \
    --header 'Authorization: ••••••'
