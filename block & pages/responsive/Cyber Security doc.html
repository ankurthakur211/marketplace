Cyber Security API Documentation

ART Cyber Security APIs

API Marketplace will be a huge plus and a great added value for Integration in al-Rajhi bank.
Cyber Security Insurance is a product provided by ART (ARG Subsidiary referred as provider) This product provides coverage to protect companies from financial losses and liabilities resulting from cyber-attacks and data breaches. The purpose of this project is to allow ARG subsidiaries (referred as consumers) to offer cyber security insurance service to their customers through subsidiary digital channels.
