List customer financial summaries

Endpoint: /mp-customer-financial/v1/summaries?

Swagger Link

This operation path is used to list customer financial summaries.

Request Example

                    
Query Params:
//CIC:
//UNN:5984578545
crnNmber:1319364818                                             
                    
                  
                    
curl --location 'https://sit.api-marketplace.alrajhibank.com.sa/apimarketplace-sit/mp-sandbox/mp-customer-financial/v1/summaries?crnNmber=1319364818&pageSize=100&page=1' \
--header 'accept-language: ar' \
--header 'Accept: application/json' \
--header 'Authorization: ••••••'
