SPL cost optimization APIs

ARG’s Centralized Cached Services for SPL have been designed to optimize efficiency and reduce the costs of consuming SPL services and time. These services leverage pre-cached data already stored by the bank.

APIs

Get Customer Address Details

Endpoint: /v1/cached-address

Swagger Link

This path retrieves customer address information from ARB using the customer ID and the last fetched date available in the bank’s system.

Request Example

                
Query Parameters:
    idNumber= 1098248663
    idType= 0

cURL

                
curl --location --globoff 'https://test.api-marketplace.alrajhibank.com.sa/apimarketplace-sit/sandbox-inbound/mp-customers/v1/cached-address?idNumber=1098248663&idType=0' \
--header 'x-request-id: d66acb1a-7696-4227-8c09-894a5429632b' \
--header 'Accept: application/json'
