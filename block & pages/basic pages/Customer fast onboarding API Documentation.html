Fast Onboarding

The Fast-Onboarding (FOB) API is an application that provides a streamlined and efficient process for onboarding new users onto Marketplace to be able to use all of its capabilities. The Fast-Onboarding API typically offers a set of endpoints to integrate it into their applications or systems seamlessly. These endpoints can automate various onboarding tasks such as user registration, identity verification and account creation. We provide multiple ways of authentications so that all customers will be able to identify the customer and get his information for registration. Also, we provide multiple sources for the customer data with different types of information, this enables users to join a platform or system quickly and start utilizing its features without any unnecessary delays.

Validate OTP For a Specific Fetching Request

Endpoint: /mp-fast-onboarding/v2/person-identification/fetch-requests/{RequestId}/otp/{OtpId}/validate

Swagger Link

Validate OTP value for the request

Request Example

                          
  Path Params:
  RequestId:1131214
  OtpId:1234
  
  Request Body:

    "Data": {
      "OtpValue": "1234"
    }
  }
