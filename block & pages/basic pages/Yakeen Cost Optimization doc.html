Get Cached Customer Yakeen Information For Resident

Endpoint: /v1/cached-resident

Swagger Link

This endpoint retrieves customer identity information from ARB based on the customer ID and the last date the data was fetched by the bank for Resident.

Request Example

                
Query Parameters:
    residentIqamaId= 32532546

--header 'x-request-id: 42162224-5975-4206-916f-37cc9a82eaa5' \
