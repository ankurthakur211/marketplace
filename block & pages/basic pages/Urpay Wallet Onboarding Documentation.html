Urpay Wallet Onboarding

Urpay Wallet Onboarding is a digital service provided by Neoleap that allows ARG subsidiaries to onboard customers to the Urpay wallet platform. The onboarding process includes verifying whether the individual is an existing Urpay customer or a previously registered prospect, and if not, creating a new prospect profile through the API Marketplace. Eligibility checks such as customer identity, mobile number, and age (based on Hijri or Gregorian birthdate) are performed as part of the process.

Create Prospect

Endpoint: /mp-prospect-registration/v1/prospects

Swagger Link

This API is used to create a new prospect only if the given POI is not urpay customer and no related prospect is found in prospects table.
