Create Prospect

Endpoint: /mp-prospect-registration/v1/prospects

This API is used to create a new prospect only if the given POI is not urpay customer and no related prospect is found in prospects table.

Get Prospect Status

Endpoint: /mp-prospect-registration/v1/prospects/{POINumber}/status?

This API is used to get prospect status.

Swagger Link

Request Example

                    
Path Variables:
    POINumber:123
Query Params:
    poiType:NAT
    birthHijriDate:1421-08-04
    birthGregorianDate:2000-10-31
                    
                    
                    
curl --location 'https://sit.api-marketplace.alrajhibank.com.sa/apimarketplace-sit/mp-sandbox/mp-prospect-registration/v1/prospects/123/status?poiType=NAT&birthHijriDate=1421-08-04&birthGregorianDate=2000-10-31' \
--header 'x-request-id: 84257628-cb41-4040-81a9-4f8590eeb24a' \
--header 'accept-language: EN' \
--header 'x-host-ip: ss' \
--header 'x-latitude: 24.7136' \
--header 'x-longitude: 46.6753' \
--header 'Authorization: Bearer AAIgMDA5NDA3ZTMwMTY1ZDhmMDVkNTU0ZTMzNmFjYjBiMjZntuQKiEEg2geLoCZjSx7b0727D0R4AHkjjm9vskhnHo9O0_kseW-_oqKbrBtWIjzm-Mw8aHhpGOMa0gaTCxbIg3J8AVXTpT_Cr5sySBREqRszXAQrScGjREAkj1gpsWmLjBLdU4pWbiy0s6y-nnER'
