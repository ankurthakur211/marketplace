About Emkan Voucher Redemption APIS

The main goal for this project is to enable Emkan to avail applying for Voucher Redemption through API Marketplace. Voucher Redemption mainly is the exchange by a Customer of a Voucher (or individual items within a Voucher) for goods or services ordinarily provided. These API’s are used for getting the voucher details [amount and current status], voucher pre-redemption, redemption, pre-refunding and refunding. Exposing these API’s can be applied for on-prem and ecommerce Emkan's Retail Finance merchants.

Refund

Endpoint: /merchant/v1/vouchers/refund

Swagger Link

This operation is performed when a voucher was previously successfully redeemed, the merchant may use the refund voucher operation to request the voucher to be placed back into an unredeemed state. Once status of the voucher is unredeemed, the customer may cancel the contract from emkan website or redeem it again.

Request Example

                                            
        {
            "customerId": "1230000000",
            "voucherId": "4818",
            "otp": "1234",
            "otpID": "fe419221-aad4-4da6-9370-1bbcd477dfbb"
            }
                                            
                                          
                                              
    curl --location 'https://sit.api-marketplace.alrajhibank.com.sa/apimarketplace-sit/api-marketplace-sit/merchant/v1/vouchers/refund' \
    --header 'MERCHANT_CODE: ARBMarketplace' \
    --header 'LNG: AR' \
    --header 'CHN: ECOMMERCE' \
    --header 'Content-Type: application/json' \
