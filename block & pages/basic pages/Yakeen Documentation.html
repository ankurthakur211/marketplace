Yakeen Integration APIS

 

Yakeen Integration is a product provided by ARB (ARG Subsidiary referred as provider). This product allows you to retrieve personal information and customer ID expiration details from Yakeen

Yakeen Person Information

 

Endpoint: /mp-yakeen/v1/arb-persons/{POINumber}

Swagger Link

It is used to describe the endpoints required for retrieving and verifying personal information such as name, date of birth, nationality, and address details from two different providers, ARB and ART, based on consumer requirements.

Request Example

            poiType:1
            birthDate:02-1987
            expiryDate:1445-08-08

Endpoint: /mp-yakeen/v1/customers/{POINumber}/id-expiration

Swagger Link

It is responsible for Retrieveing Customer ID Expiration from Yakeen.

    poiType:1
    birthDate:1979-10-13
