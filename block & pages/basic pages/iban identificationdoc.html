IBAN Identification API Documentation

IBAN Identification APIs

IBAN Identification is a service that enables businesses and organizations to verify a beneficiary’s IBAN before initiating a transfer. It provides real-time access to essential IBAN details through the Saudi Payments Network, ensuring that the bank account is valid and active.

This service automates and simplifies the IBAN validation process, reducing errors and enhancing transaction security.

The IBAN Identification Callback feature retrieves validated IBAN information from trusted sources and pushes the data back to the user based on the submitted request.
