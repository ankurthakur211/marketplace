Customer Basic Data

Endpoint: /mp-corporate/v1/inquire{ReferenceId}

Swagger Link

The endpoint is used to return corporate basic data like the name, ID information, mobile number and gender.

Request Example

                        
    Query Params:
    customerStatus:1
    page:1
    pageSize:10
    
    Path Variables:
    ReferenceId:7003259999
                        
                      
                        
    ccurl --location 'https://sit.api-marketplace.alrajhibank.com.sa/apimarketplace-sit/mp-sandbox/mp-corporate/v1/inquire/7049409151?customerStatus=1&page=1&pageSize=10' \
    --header 'x-request-id: cac6cc0a-e79f-47c6-9fae-2e77d57012ea' \
    --header 'accept-language: EN' \
    --header 'Authorization: ••••••'
