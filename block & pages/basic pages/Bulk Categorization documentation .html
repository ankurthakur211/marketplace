Categorize Bulk Merchant

Endpoint: /merchants/categorize/bulk

Swagger Link

This API utilizes the Drahim AI Engine to classify and categorize the given merchant based on the provided information.

Request Example

                    
Request Body:
    {
        "Data": {
            "Merchants": [
                {
                    "MerchantName": "flynas",
                    "MerchantId": "string",
                    "MerchantMccCode": "string",
                    "MerchantPaymentType": "string"
                }
            ]
        }
    }
