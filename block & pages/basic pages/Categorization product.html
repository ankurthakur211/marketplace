Description

What is the API Marketplace?
- Categorization is an AI-powered service provided by Drahim (an ARG Subsidiary).
- It classifies merchants based on their business type and allows customers to modify or update classifications when required.

What is a Categorization?
- Categorization Service: An AI-powered solution that classifies merchants into predefined business categories based on their business type and transaction data.

Description

What The Categorization Does:
- Automatically classifies merchants using AI.
- Allows customers to update or modify classifications when needed.

How Will It Be Used (B2B)?
- Your business (Consumer) integrates with the API Marketplace to offer merchant categorization services to your customers through digital channels.

How It Works (Business Flow): Customers send merchant details → API Marketplace processes → Categorization result is returned.

Advantages of Categorization (Business View)

- Provide accurate merchant classification without building your own AI solution.
- Unified and standardized access through the API Marketplace.
- Faster time to market for subsidiaries by reusing a ready service.
- Centralized monitoring, analytics, and security compliance.

Terminologies (Business Definitions)

 

  • Merchant

    A business entity that provides goods or services.

  • Categorization

    Assigning merchants into predefined business categories (e.g., Food & Beverage, Electronics, Retail).

  • Merchant Category Code

    Standardized 4-digit code used globally to classify merchants.

  • Consumer

    Subsidiary using the service.

  • Customer

    End user interacting with the categorization service.

 

 

Key Features

 

 

  • Categorization Capabilities

    - Ability to process and classify a bulk list of merchants in a single request.
    - Automatic classification into predefined business categories using AI.
    - Support for multiple data attributes (merchant name, type, transaction history, etc.).
    - Fast response time (2–5 seconds) even for large volumes of merchants.

  • Review & Update Capabilities

    - Customers can review classification results directly through the digital channel.
    - Option to modify or update incorrect classifications before final confirmation.
    - Immediate reflection of updated classifications in the system.
    - Clear audit trail of changes for monitoring and compliance.

  • Integration & Access

    - Unified and standardized API access via the API Marketplace.
    - Scalable architecture to handle increasing transaction volumes.
    - Consistent categorization logic across all subsidiaries.

  • Reporting & Notifications

    - Real-time confirmation of categorization requests with unique reference IDs.
    - Status updates for bulk processing (in-progress, completed, or failed).
    - Exportable categorized merchant lists for business reporting.
    - Notifications and logs stored centrally for monitoring and analytics.

 

Inputs / Outputs Samples

 

  • Inputs (Business Perspective):
    - Customer identification details (basic account or login information).
    - Bulk merchant list (merchant names, IDs, and attributes).
    - Transaction or business activity data for each merchant.
    - Optional classification parameters (e.g., category type, rules).

  • Outputs (Business Perspective):
    - Categorized merchant list with assigned business categories.
    - Confirmation of successful processing with unique request IDs.
    - Status of request (in-progress, completed, or failed).
    - Updated classifications reflecting any customer modifications.
    - Exportable categorized data for reporting or analytics.
