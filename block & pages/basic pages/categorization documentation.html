Categorize Vote

Endpoint:/mp-categorization/v1/merchants/category-vote

Swagger Link

This path to help Drahim AI Engine to categorize better by passing the user change of merchant category, this change will be handled as a vote on the category. Drahim Engine analyzes the votes and enhances its self to give better results.

Request Example

                        
    Request Body
    {
        "Data": {
          "MerchantId": "01J46X0AAECE5RV653B6ACJN8A",
          "UserId": "string",
          "CategoryId": "14"
        }
    }
                        
                      
                        
    
    curl --location 'https://sit.    api-marketplace.alrajhibank.com.sa/    apimarketplace-sit/mp-sandbox/    mp-categorization/v1/merchants/    category-vote' \--header 'x-request-id:     27e3609e-c7eb-4195-8881-96308d109415' \--header 'Content-Type: application/json' \--header 'Accept: application/json' \--header 'Authorization: ••••••' \--data '{  "Data": {    "MerchantId":         "01J46X0AAECE5RV653B6ACJN8A",    "UserId": "string",    "CategoryId": "14"  }}'

    Response

200 422 
    
                          
    {
        "Data": {
            "VotingMessage": "thanks for sharing the vote, system will be better because of you"
        }
    }

Categorize Merchant For ARB

Endpoint: /mp-categorization/v1/merchants/categorize

Swagger Link

This path is used to utilize Drahim AI Engine to categorize the passed merchant.

Request Example

                                    
    Request Body
    {
        "Data": {
          "MerchantName": "stc pay",
          "MerchantId": "string",
          "MerchantMccCode": "string",
          "MerchantPaymentType": "string"
        }
    }                                                 
                                    
                                  
                                      
    curl --location 'https://sit.api-marketplace.alrajhibank.com.sa/apimarketplace-sit/mp-sandbox/mp-categorization/v1/merchants/categorize' \
    --header 'x-request-id: f0774dc2-6d0c-4d50-ad3a-65fd0c1d958d' \
    --header 'Content-Type: application/json' \
    --header 'Accept: application/json' \
    --header 'Authorization: ••••••' \
    --data '{
    "Data": {
    "MerchantName": "stc pay",
    "MerchantId": "string",
    "MerchantMccCode": "string",
    "MerchantPaymentType": "string"
    }
    }'
