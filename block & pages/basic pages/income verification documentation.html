These APIs are intended to describe the endpoints required for managing account links. Through this API, consumers can link their accounts with financial institutions in order to retrieve information from linked accounts. Additionally, consumers can inquire about existing account links and revoke a specific link when needed.

Create Account Link

This API is used to generate a dedicated URL that allows the user to link their account with a financial institution. Upon a successful request, the API returns a redirection URL where the user can enter their credentials and authorize the account linking process.

  • The system sends a request to the Create Account Link API.
  • The API responds with a unique redirection URL for the user.
  • The user will enter their bank account credentials.
  • This API is not available for testing.
