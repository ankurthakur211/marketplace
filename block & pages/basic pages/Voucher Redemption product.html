About Emkan Voucher Redemption

 

  • API Marketplace is offering all al-Rajhi group to share their most consumed APIs in its portal to make it easy to call external entities and call each other with low-rate API call.
  • Emkan publishing Voucher Redemption API’s services for in our API marketplace portal to be consumed by anyone of al-Rajhi group company.

 

Key Concepts

 

  • The main goal for this project is to enable Emkan to avail applying for Voucher Redemption through API Marketplace.
  • Voucher Redemption mainly is the exchange by a Customer of a Voucher (or individual items within a Voucher) for goods or services ordinarily provided.
  • These API’s are used for getting the voucher details [amount and current status], voucher pre-redemption, redemption, pre-refunding and refunding. Exposing these API’s can be applied for on-prem and ecommerce Emkan's Retail Finance merchants.

 

 

Expose APIs as Self-Service Products

  • APIs

 

 

Voucher Details

It is exposed for retrieving the voucher details (voucher's current amount and status). Read more

 

Pre-redeem

This api is exposed for generating the otp (that is being sent to user's mobile number and otp id to the merchant, each of the otp and otpID are associated) before redeeming the voucher. Read more

 

Redeem

This operation is performed when a voucher is used as a form of payment. When used as a form of payment the consumer redeems the requested amount against the voucher. Once redeemed, the voucher may not be used again. Read more

 

Pre-refund

It is exposed for generating the otp (that is being sent to user's mobile number and otp id to the merchant, each of the otp and otpID are associated) before refunding the voucher. Read more

 

Refund

This operation is performed when a voucher was previously successfully redeemed, the merchant may use the refund voucher operation to request the voucher to be placed back into an unredeemed state. Once status of the voucher is unredeemed, the customer may cancel the contract from emkan website or redeem it again. Read more
